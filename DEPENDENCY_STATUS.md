# Dependency update status

This is a partial security update to the existing Python 3.10 lock, not a
complete speech-stack migration or a deployable replacement environment.

The targeted patch updates 20 existing lock entries and adds aiohappyeyeballs
and propcache for aiohttp. Requests 2.32.5 permits the patched urllib3 2.8.0;
pyasn1-modules 0.4.2 permits pyasn1 0.6.4; packaging 24.2 supports wheel 0.46.2.
Other fixes cover aiohttp, fonttools, fsspec, GitPython, grpcio, Mako, msgpack,
Pillow, protobuf, PyArrow, setuptools and Werkzeug. Unchanged package records
are preserved. Every changed release hash comes from its versioned public PyPI
metadata. Source build hooks are not part of the smoke-test installation.

Local comparison with the reviewed public high/critical advisory snapshot of
2026-10-24 gives 109 distinct package/advisory matches before and 39 after:
28 Pillow, 3 Torch and 8 Transformers. This is version matching, not a statement
that all matches are reachable or that the entire application is safe.

## Existing installation blockers

- `Pipfile` requests `pyannote.audio==2.1.1`, whose published metadata requires
  `torchaudio<1.0`. The same Pipfile requests `torchaudio==2.0.1`. The checked-in
  lock instead contains `pyannote.audio==1.1.2`. These requirements already
  disagree before this change. The application imports the version 2 VAD API
  and configures `pyannote/segmentation`, so choosing a new VAD release and
  validating its checkpoint is a runtime/model migration.
- `hf-rvc` is in Pipfile but absent from the lock and unavailable from public
  PyPI at review time. Its optional application path imports `hf_rvc`. A
  released source/artifact and installation policy must be selected; this
  change does not substitute an unmerged branch or silently remove RVC.
- The unchanged Whisper 20230314 source declares `triton==2.0.0` on Linux x86-64.
  That dependency is absent from the existing lock. A newer Torch stack requires
  rechecking Whisper as well. Whisper and several
  other legacy dependencies have source-only releases.
- Python 3.10 reached end of life on 2026-10-01. Moving to 3.11 also requires
  updating the locked NumPy/Numba/audio stack. Pillow 13 requires Python 3.11;
  Pillow 12.3.0 removes earlier fixes' matches but leaves 28 current alerts.

The lock was patched narrowly rather than regenerated by a resolver. Its
pre-existing Pipfile hash is deliberately preserved: `pipenv verify` reports
the stale lock both before and after this change. Do not interpret the CPU
tests as a successful `pipenv sync` or a complete installation recipe.

## Concrete next candidate

The minimal tested family in related audio work is Python 3.11,
Torch/TorchAudio 2.7.1 with CUDA 11.8, and Transformers 4.48.3. Torch 2.6.0 and
Transformers 4.48.0 are the minimum upstream patches for the old deserialization
issues. Pyannote.audio 3.3.2 declares Torch >=2 and TorchAudio >=2.2, unlike
2.1.1, but requires a VAD/checkpoint compatibility test before adoption.
The current Whisper release and a reproducible RVC artifact must be evaluated
alongside it. No model download, model licence acceptance or GPU inference was
performed for this patch.

A generated tiny GPT2 model passes a native CPU forward and weights-only load
with Torch 2.7.1+cpu / Transformers 4.48.3 in a separate environment. That
candidate-only check does not verify this application's T5 tokenizer, VAD,
Whisper or RVC paths; these ML pins are not changed in this patch.

## Validation scope

`tools/smoke_requirements.py` exports 65 exact hash-pinned public packages from
the lock. Tests exercise the real VOICEVOX HTTP adapter against loopback,
aiohttp loopback requests, training's `Dataset.from_dict` path and Arrow IPC, native Pillow image codecs
with Matplotlib/fonttools, TensorBoard protobuf messages, grpcio, fsspec,
msgpack, Mako, pyasn1, Werkzeug and local GitPython operations. CI installs only
binary wheels and does not start the chatbot or download models. Hugging Face
downloads and telemetry, and Gradio telemetry, are disabled.

Static inspection of published dependency metadata finds no new declared
conflicts for Python 3.10 on Windows or Linux. It cannot establish the complete
legacy environment: CUDA wheel metadata and the dependency declarations of
four unchanged source-only packages were not fully evaluated. The manually
reviewed Whisper declaration exposes the pre-existing missing Linux Triton
dependency; the candidate introduces no additional missing dependency.

The release workflow runs only on master/alpha/beta. Its npm installation now
disables automatic audit and funding requests. The feature branch has a
separate read-only CPU test workflow, with no release/deployment step.
